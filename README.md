#### Side projects

Small tools that solve problems I actually have, built to production standards: tests, CI
and docs.

- **[agent-tabs](https://github.com/levadadenys/agent-tabs)**: brings back your terminal
  windows of AI coding agents (Claude Code, Codex, Grok) after a crash or reboot, with each
  session resumed in its own tab and directory. macOS + iTerm2, no dependencies.
- **[power-watch](https://github.com/levadadenys/power-watch)**: tells a Telegram channel when
  the power goes out at home. It uses a cheap Xiaomi Wi-Fi lamp as the sensor and runs on a
  Raspberry Pi.
- **[helpers](https://github.com/levadadenys/helpers)**: everyday scripts, plus a TypeScript
  workspace for algorithms and type-level programming.
